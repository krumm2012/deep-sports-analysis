# camera05：Pose标识一轮并重训五阶段模型

结果入口：http://127.0.0.1:8768/projects/camera05_custom/semantic-pose-v2/

本轮由用户授权：使用一个已人工标注视频，按Pose标识其余训练视频；不确定部分排除后直接重训。检查81段训练视频，21段原始留出验证只做预测。不合并102段拟合，不改MoSeq checkpoint；本轮重训的是五阶段姿态分类器。

原始人工文件保存在semantic-pose-v2/user-annotation.json（完整视频00_30，7区间）。两类明确单阶段、四个混合区间、一个无效区间均原样保留。混合区间备注仅约束允许出现的阶段，不等于精确边界。另对4段训练视频的动作图集建立58个助手画面/姿态参考区间，参考不是人工真值；停顿13_10的部分画面另作排除。00_30开头无效区间不进入拟合。

特征：每帧以髋部为中心、按肩髋尺度归一化的19关节坐标；±4帧位置、速度、局部变化与髋部速度，共192维。上下文止于当前视频边界。训练与推断使用相同特征，未使用MoSeq状态编号。模型为加权标准化后的逻辑回归与ExtraTrees共识组合，固定随机种子31，无需GPU。

筛选：关键点最低置信度0.55、观测覆盖至少80%；排除长静止姿态；两分类器同意、平均分数≥0.70、首二类差≥0.25、距离参考姿态不超过整段参考视频留出距离的95分位数。阶段边界各保护2帧，自动短片段排除。分数不是校准概率。参考整段留出中两模型一致且分数≥0.80却与原参考标签冲突的帧直接排除，不改原始文件，也不自动填回。筛选前核对和全部分歧保存在summary.json及reference-conflicts.json。

完成一轮自动标识后重新拟合：人工来源权重2、助手参考1、自动来源初值0.20，再限制自动样本总质量不超过全部参考样本。每帧实际训练权重保存在training.npz。labels.json覆盖全部81段完整时间轴，phase=null表示未采用；各类来源分别记录。完整原始标注保留在独立文件，不将自动记录伪装成人工确认。

结果以summary.json、verification.json为准。当前使用79段中的13,198帧，7,059帧未进入训练；其中两段整段无可靠目标。原81段总20,257帧。102个预测文件均按25fps/原帧数对齐。训练目标和21段验证严格不重叠。模型、原始输入和代码哈希可核对；训练代码快照保存在training-code.py。

人工00_30的回位/移动长区间与其他参考存在明显分歧；筛选前内部一致率低。筛掉分歧不是证明模型正确。助手参考的较高留出一致率也不等于独立人工准确率。仍只有一个完整人工标注视频，不能声称完整五阶段准确率或已优于旧模型。

模型输出：model.joblib；参考模型anchor-model.joblib；逐帧预测predictions/*.npz及JSON；全部标签labels.json。training.npz保存实际拟合的特征、类别、权重、视频ID与来源。旧MoSeq和weak-v1模型均保留。diagnostics-before-conflict-screen/保留排除参考分歧前的诊断版本，供追溯，不作为当前结果。

## 微调新模型自动标识

入口：semantic-pose-v2/edit/。结果页的“微调新模型自动标识”会传入当前训练视频编号，编辑页载入最终v2模型预测。灰色区间作为“无法判断”保留，未自动确认为人工标签。已确认的00_30及最新人工草稿原样保留，旧手工214帧边界也带入；新编辑页使用独立localStorage键，不覆盖旧完整视频标注进度。21段验证仍进入单独验证页面。

选择视频及“选择要微调的区间”，用阶段下拉框修改；在当前帧拆分，或合并下一段；相邻边界可按1帧（0.04秒）前后移动，也可直接输入起止秒。完成后“确认整段视频标注”。修改自动保存，导出camera05-pose-v2-adjusted-labels.json包含已确认视频标签和全部待确认草稿；“恢复导出文件”可恢复。确认前要求全片连续覆盖，未确认自动建议不会导出为人工训练记录。

此导出沿用schema3，使用独立registry：

```sh
PYTHONPATH=src .venv/bin/python -m dsa.pages.semantic_clip_labeling validate \
 data/projects/camera05_custom \
 data/projects/camera05_custom/semantic-pose-v2/edit/candidates.json \
 /absolute/path/camera05-pose-v2-adjusted-labels.json
```

导出记录保留原模型SHA和原自动建议，可区分人工修改与预测来源。编辑与确认不会自动启动训练；导出的文件可交回聊天核对后纳入后续训练。

### 拖动连续阶段边界

编辑页现在支持时间轴色条下方的蓝色拖动柄，以及当前区间的起点/终点滑动条。拖动任何共享边界时，左段终点与右段起点同步，按25fps对齐到整数帧；相邻区间各至少1帧，不能越过邻近边界。视频随拖动定位到边界帧，松手保存并转为待确认。时间轴手柄也支持方向键逐帧、Shift+方向键5帧、Home/End到允许范围端点。

“衔接引拍→挥拍→随挥”只填补这些阶段顺序之间不超过10帧（0.4秒）的“无法判断”间隔，初始共享边界取短间隔中点，再由用户拖动。也合并这三个阶段内同标签碎片。不会跨无效动作、混合区间、长停顿或逆向阶段补齐，不强制每个视频完整出现五阶段。操作后可立即“撤销衔接”；继续进行其他修改后该撤销备份失效，避免覆盖后续修改。原始预测不变，导出保留continuity_sources记录供追溯。

队列ID、浏览器保存键及导出registry保持兼容，原有人工进度不会自动改写；本功能不会自动启动训练。
